# Demonstração
1. Execute o SQL e configure o .env conforme README.
2. Inicie Flask; abra o painel e capture a tela inicial.
3. Cadastre Grupo Alfa, Água, cenário simulado, prioridade alta. Capture o registro e os indicadores.
4. Clique Editar, escolha Atendido e salve. Capture a mudança.
5. Exclua o registro e verifique o painel. Teste cadastro sem chave: deve falhar.
6. Execute servidor e cliente TCP e capture a resposta. Confira logs/acoes.log.
7. Execute pytest e capture os resultados efetivos. Consulte o clima quando houver internet.
